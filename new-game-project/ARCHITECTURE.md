# Office Shift — Godot Port Architecture (Prototype Parity)

> Methodology: godogen `engines/godot.md`. Target: port the Three.js/cannon-es
> prototype (`src/game/*.ts`) to Godot 4.7 / C# / Jolt, 1:1 mechanics parity.
> Read `godot.md` for scene-generation rules before touching anything.

## Hard-won environment rules (this Windows box — DO NOT rediscover)

1. **`<AssemblyName>` in `OfficeShift.csproj` MUST equal `application/config/name`
   ("Office Shift") VERBATIM including the space.** Godot resolves the project
   assembly by that exact string; mismatch => silent ".NET: Failed to load
   project assembly" and every script becomes uninstantiable.
2. **Exactly ONE `SceneTree`-derived class may exist per assembly**
   (`scenes/BuildScenes.cs`). A second subclass compiles but is silently
   uninstantiable via `--script`.
3. Invoke Godot via the **console exe**, never piping stdout through PowerShell:
   ```
   $dir = (Get-ChildItem "$env:LOCALAPPDATA\Microsoft\WinGet\Packages" -Directory |
           Where-Object Name -match 'Godot' | Select-Object -First 1).FullName +
          "\Godot_v4.7.2-stable_mono_win64"
   $env:DOTNET_ROOT = "$env:USERPROFILE\.dotnet"
   cmd /c "`"$dir\Godot_v4.7.2-stable_mono_win64_console.exe`" --headless ... > out.txt 2>&1"
   # via Start-Process cmd.exe with WorkingDirectory=project; read out.txt after WaitForExit
   ```
4. Build gate order: `dotnet build` -> `--headless --import` -> run/boot.
5. First-run editor setup already done (API assemblies exist next to the exe).

## Scene topology

- `scenes/world.tscn` — ALL static office geometry + colliders. Generated at
  build time by `scenes/BuildScenes.cs ++ world` from `scripts/WorldData.cs`
  tables (ported from `src/game/world.ts`). Root Node3D "World" carries
  `World.cs` (runtime query API attached by builder).
- `scenes/main.tscn` — bare Node3D "Main" + `GameMode.cs`, generated by
  `BuildScenes.cs ++ main`. GameMode instances world.tscn and spawns all
  runtime entities in `_Ready`.
- Everything else (player, NPCs, blood, ragdolls, HUD, audio) is constructed
  in C# at RUNTIME. No serialization constraints apply to runtime-built nodes.

## Parity checklist (mechanics that MUST survive the port)

- Shift timer 360s -> timeout loss; win = steal blueprints (hold E 3.5s at
  server terminal) then deliver at mail trolley (E).
- Bonk (F): range 2.1, forward-cone dot > 0.35, cooldown 0.8s; victim KO ->
  ragdoll flop away from player; 4 blood splats size 1.1; witnesses within 4m
  or LOS get +70 sus (+100 if woken Slob); disguise blown.
- Carry (Q): pick up nearest Out+visible body <= 2.4m; carried bundle viewmodel;
  move speed 2.9; drip splat every 0.9m; drop = second flop + splat; hide at
  hide spot (capacity) -> Hidden state, investigations of that body shrug off
  (+40 min sus); hide-spot gag props (lamp/trolley lump/shoes).
- Mop: pickup at supply closet; hold E 2.2s on nearest splat <= 2.4m removes it;
  investigators of that stain shrug off (+35 min sus).
- Disguise: E on unlooted body -> suspicion gain x0.3; blown by witnessing
  bonk or being seen while carrying.
- Photocopy face (E at printer, 30s cd): awake non-reporting NPCs within 12m
  get 7s distraction (skip perception entirely).
- Suspicion model: activity score {server room 1, hacking 2.5, mopping 1.5,
  carrying 3}; gain when visible = activity * archetype.rate * 22 * disguiseMul
  * dt; creep <1.6m = 9*rate*dt; crouch-walk <8m = 5*rate*dt; decay 2.5/s while
  unseen & <50.
- Vision: range * mul * (crouch ? 0.65), FOV half-angle vs facing yaw,
  2D segment vs vision-blocker AABBs for LOS.
- Curiosity chain: routine NPC seeing body (full range) or blood (range*0.8)
  -> walk to it (speed*0.9) -> arrival starts panic countdown (body 8s /
  blood 4.5s, per-second emote); evidence vanishing mid-chain shrugs off
  (+12 investigate / +40 panic / +35 mopped); expiry: Grifter -> accomplice
  (sus 20), reports:true -> sprint to guard (speed*1.7).
- Report reaching guard -> hunt 20s alert: chase last-seen pos, catch <1.5m =
  lose; give up after lost-sight >6s (>4s post-arrival) or alert expiry.
  Guard personally seeing carry/body/blood -> hunt 15/14/12s.
- Gossip: sus >= 60 once -> +30 sus to all awake NPCs within 9m.
- Sus >= 100 climax: grifter accomplice else report.
- Chatter toast every 11-18s from AMBIENT_LINES with random awake name.
- Stats tracked: bonks, hides, reports, disguises, cleans (HUD end card).

## Emote policy

Text emotes via Label3D (billboard, outline): "?" curious, "!!{N}" panic
countdown, "!!" report, "Z z z" sleeping/boned-out, ":D" laughing. Do NOT use
emoji glyphs (font availability not guaranteed).

## Verification commands per module

```
$env:DOTNET_ROOT = "$env:USERPROFILE\.dotnet"
& "$env:USERPROFILE\.dotnet\dotnet.exe" build   # in a SCRATCH robocopy of the project
```
Parallel agents MUST build inside their own scratch copy (robocopy
new-game-project -> %TEMP%) to avoid obj/ lock contention, then hand off.
Integration lead runs the authoritative chain in-tree afterwards.
